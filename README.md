* SISTEM ABSENSI *
ini adalah proyek yang menunjukan contoh sistem absensi yang baik dan memudahkan mahasiswa dalam memanegement absennya dalam satu semester.
dibuat dengan tampilan kalender supaya memudahkan mahasiswa dalam menghitung hari-hari nya yang sudah berlalu dan yang akan datang.
**Tampilan**
saya sengaja membuat tampilan sistem absensi sederhana dan mudah untuk menampilkannya. cukup masukan nim mahasiswa semester 3 dan katasandinya adalah mahasiswa123, dashboard pun akan tertampil dengan baik.

** Pengembangan Kedepan **
saya berharap untuk versi-versi yang akan datang, saya akan menambahkan fitur-fitur :
1. tambah X untuk alpah di tanggal kalender
2. tambah S untuk sakit di tanggal kalender
3. tambah I untuk izin di tanggal kalender - serta deskripsi izin
4. tambah Y untuk kegiatan kampus yang mengharuskan tidak mengikuti perkuliahan

saya juga akan membuat akun dosen untuk menjadi admin dalam memantau sistem absensi tersebut, saya harap ini akan memudahkan perkerjaan dosen, serta mahasiswa dalam manejemen tugas dan rutinitas perkuliahan.
